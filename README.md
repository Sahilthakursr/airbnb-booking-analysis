# 🏠 Airbnb Booking Data Analysis – NYC

This project analyzes Airbnb booking data for **New York City** using Python libraries such as **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn**. It explores patterns in pricing, host activity, property distribution, and traveler preferences to uncover key insights useful for both hosts and potential customers.

---

## 📁 Project Structure

- `airbnb_data_analysis.ipynb` – Jupyter Notebook containing full analysis and visualizations  
- `README.md` – Project documentation

---

## 🧰 Tools & Libraries Used

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 🔍 Key Questions & Analysis

1. **💸 Price Distribution**  
   - Visualized the spread of Airbnb prices across listings in NYC.
   - Helps identify pricing trends and detect outliers.

2. **🏙️ Property Counts by Location**  
   - Total listing count by neighborhood and neighborhood group.
   - Reveals which areas are most saturated with Airbnb options.

3. **📊 Average Pricing by Area**  
   - Calculated and visualized average listing prices across various neighborhoods and boroughs.
   - Useful for pricing strategies and traveler budgeting.

4. **⭐ Top Hosts & Popular Neighborhoods**  
   - Identified hosts with the most listings and high-activity neighborhoods.
   - Highlights market leaders and demand hotspots.

5. **🛏️ Room Type Distribution**  
   - Compared availability of entire homes, private rooms, and shared rooms across NYC.
   - Assists users in understanding accommodation trends.

6. **📆 Stay Duration Requirements**  
   - Analyzed minimum nights required per listing.
   - Important for both travelers and platform compliance.

7. **📝 Review Activity**  
   - Total and maximum reviews by borough and room type.
   - Indicates customer engagement and listing popularity.

8. **📍 Best Locations to Stay**  
   - Identified top listings and neighborhoods based on price and reviews.
   - Great for suggesting traveler-friendly options.

---

## 📊 Summary of Insights

- Manhattan and Brooklyn have the highest number of listings and the widest price range.
- Private rooms are more common than entire apartments in densely populated areas.
- Top hosts tend to have multiple listings in high-demand neighborhoods.
- Listings with lower prices and higher review counts dominate bookings, suggesting competitive pricing is key.
- Some neighborhoods show high prices with fewer reviews, indicating either exclusivity or overpriced properties.
